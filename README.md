# Chatbot with LLM

A simple AI chatbot built using Python, Streamlit, LangChain and an LLM.

## Features

- Chat with an AI using natural language
- Built with LangChain
- Streamlit-based user interface
- Uses an LLM to generate responses
- Simple and easy-to-use chatbot interface

## Technologies Used

- Python
- Streamlit
- LangChain
- LLM
- Git & GitHub
